# LLM Wiki + OKF Every Local AI Now Shares ONE Memory

## Summary

The text discusses challenges in implementing memory systems for local AI models, highlighting the limitations of traditional approaches like RAG (Retrieval-Augmented Generation) and the need for a more integrated solution. It describes an attempt to create a memory system using concepts from Karpathy's LLM Wiki and Google's OKF spec, involving a 'librarian' agent to manage memory and a deterministic approach to indexing and linking. The goal is to create a private, personalized AI that remembers context across sessions.

- The system uses deterministic indexing and linking to ensure memory is organized and accessible, with rules to prevent duplication and maintain consistency.
- The memory system is designed to be local, private, and persistent, allowing AI to retain context across sessions and tools.
